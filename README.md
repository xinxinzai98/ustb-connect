# 北科校园联网 · USTB Connect

Windows x64 与 macOS Apple silicon 的校园网连接管理应用。当前版本 **1.0.0**，仅适配北京科技大学的认证流程。

支持无线配置验证、多个校园网账号、自动重连、可选 IPv6 关联、余额/流量、开机设置、日志与独立停止入口。

## 模式与配置

- **模拟模式**使用模拟网络与示例数据，不更改无线连接、不提交校园网认证。
- **后台服务模式**执行真实检测与认证。Windows 使用 SYSTEM 计划任务，Mac 使用 LaunchDaemon；须由用户安装并启用，不自行提权安装。

切换到模拟模式不会停止实际后台。界面持续显示实际后台状态；“停止全部监测”同时请求停止模拟与实际后台，并分别核验结果。无法确认时明确提示，不能当作已停止。

1. 在“无线网络”填写本机使用的名称、密码及安全类型。支持 WPA2/WPA3 个人网络与开放网络，暂不支持企业级 802.1X 无线认证。
2. 保存后选择“连接并验证”。实际验证会重新关联指定配置，检查 SSID、所用配置和可用 IPv4 地址，可能短暂断网。保存成功不替代连接验证。
3. 在“校园网账号”添加或导入账号，最多 12 个。编辑时密码留空表示保留原密码。
4. 在“重连设置”安装并连接后台服务。可将本机配置导入尚无账号的后台；示例凭据及模拟验证结论不会当作真实配置验证。
5. 在后台模式完成无线验证，保存检测间隔与开机设置，再启动自动重连。

后台版本与界面不一致时须更新后台。旧版脚本任务正在运行时，安装器停止安装，不自动修改旧任务或凭据。

## 认证与备用策略

正常连接保持当前账号。仅明确账密失效、账号停用或额度不足，才暂停该凭据并在全局认证间隔结束后尝试备用。DNS、线路、频控、设备上限或验证码不换号。

每次提交前重新核对无线网络、接口和源地址，只向固定北科地址发一次 POST，携带可用 IPv6 源地址。不主动注销，不关闭证书校验，不伪装 MAC/UA，不修改 DNS、网卡或防火墙。

认证状态未知且没有校园拦截证据时，不自动提交密码。明确离线时短间隔复核；恢复须核对账号身份及可信 IPv4 HTTPS，IPv6 单独检查。

默认正常检测 30 秒、异常确认 5 秒、连续失败 3 次、认证间隔 300 秒，可在规定范围调整。网络请求耗时影响实际恢复时间。

## 余额与流量

仅查询当前在线且匹配已配置账号的数据。身份变化、网络变更或认证失效后，不把旧账号及缓存余额显示为当前账号。账号列表保留各自的历史记录和更新时间。

余额遵循校方前端预付费条件：`fsele == 1` 时 `fee1 / 10000` 为元。流量取 `visitor/loadUserFlow` 的 `data.v4`、`data.v6`，保持校方 **MB** 单位。缺失为 `—`，有效 0 保留为 0。接口未给统计周期，不标注“本月”或“本次会话”；实际账单仍需现场核对。

## 停止与开机

主窗口和托盘均提供“停止全部监测”。安装后台后，桌面另有“停止北科自动联网”入口，可独立于界面请求停止后台。停止状态持久保存，重开界面不会自行恢复；关闭界面不等于停止后台。

停止请求优先于账号/配置保存；已交给系统或服务器的请求不能撤回，取消后不继续追加自动认证。卸载或移除界面前应先停止后台。

无人登录运行依赖系统服务、凭据存储与无线权限。Mac FileVault 解锁前不能运行普通系统后台。真实关联、系统权限与开机行为须按 [TESTING.md](TESTING.md) 在目标系统验收。

## 账号文件

单账号：

```json
{"username":"YOUR_CAMPUS_ACCOUNT","password":"YOUR_PASSWORD","label":"主用账号"}
```

多账号：

```json
{"accounts":[
  {"label":"主用账号","username":"ACCOUNT_A","password":"PASSWORD_A","enabled":true},
  {"label":"备用账号","username":"ACCOUNT_B","password":"PASSWORD_B","enabled":true}
]}
```

仓库和安装包不含真实账密、令牌或个人配置。导入来源文件保留在原位置，应用不会自行删除。

## 数据与日志

界面使用操作系统安全存储；后台使用 Windows DPAPI LocalMachine 或 Mac System Keychain，并限制文件权限。不可用时拒绝保存，无明文降级。密码不回填，不进入命令行、日志、URL 或诊断导出。

Windows 后台目录 `C:\ProgramData\BKQL Connect`；Mac 为 `/Library/Application Support/BKQL Connect`。保留目录和服务标识用于升级，与无线名称无关。

`diagnostics.jsonl` 保存逐轮日志，5 MB 后轮转一份；`status.json` 为心跳。界面显示最近 200 条，重启恢复历史记录。脱敏导出不含密码、完整账号、账单或认证原文。控制接口只监听回环地址。

## 开发与构建

```sh
npm ci
npm test
npm run icons
npm run preview
npm run package -- --mac --arm64
npm run package -- --win --x64
```

Mac 构建使用 Apple Command Line Tools 编译 CoreWLAN 助手，打包时自动编译。原生生成文件、依赖、截图、测试输出、私有配置和安装包不进入 Git。

可设置 `USTB_TEST_POWERSHELL` 运行使用桩函数的 Windows 查询测试，不调用真实网络接口；未配置的非 Windows 主机会明确跳过该项。

本地测试不替代 Windows 原生安装、真实 Wi-Fi、Mac 权限/钥匙串、无人登录启动及真实校园认证。具体边界见 TESTING.md。安装包尚未做开发者签名或公证。
